# Congregation Figma content assets

These individual content assets were exported from the Congregation design owned by the project. Their provenance and SHA-256 digests are recorded in `sources.json`.

- `coastal-house.png`: Asset Library preview and local reference asset (1536 × 1024).
- `mountain-study.png`: Original canvas artwork and local reference asset (1536 × 1024).
- `playhead-marker.svg`: Original 22 × 26 playhead alpha mask.
- `playhead-line.svg`: Original colored playhead layer, composed through the alpha mask by TimelineView.

The application uses the native LVRS icon library for named controls. No whole-screen screenshot, remote URL, Qt resource collection, or web runtime is used by these assets. Screenshots captured for visual comparison stay under `build/`.
