# 타임라인 레이어 콘텐츠 미리보기

Figma `353:4887`의 타임라인에서 시각 레이어 이름 앞의 18×18 영역은
도구 종류 아이콘이 아니라 해당 레이어 콘텐츠의 미리보기이다. 래스터,
벡터, 비디오와 공간 조건부 콘텐츠는 현재 프레임의 자산을 표시한다.
숨긴 레이어에서도 콘텐츠를 확인할 수 있어야 하며, 프레임 범위 밖이나
빈 콘텐츠는 중립 배경의 빈 미리보기로 표시한다. 공간 이미지가 없는
임베딩은 가상의 그림을 생성하지 않는다. 오디오 트랙은 Figma의 오디오
아이콘과 독립적인 시간 눈금을 유지한다.

미리보기는 원본 자산의 비율과 투명도를 보존한다. 레이어 자체의 콘텐츠를
보이기 위해 가시성·불투명도·레이어 변환과 합성 효과는 적용하지 않는다.
래스터 축소는 출력 픽셀당 최대 8×8 표본으로 근사하므로 매우 가는 획이나
작은 점은 보이지 않을 수 있다. 페인트 포인터 이벤트나 타임라인의 매 화면 다시 그리기에서
전체 문서를 복사하거나 축소하지 않는다. 문서 편집이 확정되면 갱신하며,
프레임을 이동할 때는 자산이나 영상 프레임이 바뀐 레이어만 다시 만든다.
미리보기는 표시 전용이며 문서, 원본 픽셀과 Undo/Redo 이력을 바꾸지 않는다.

검사는 서로 다른 레이어와 투명·빈 콘텐츠, 숨김 상태, 동적 키프레임과
영상 프레임, 벡터 및 UI 상의 18×18 배치와 갱신을 다룬다. 실제 앱 실행
검증은 명시적으로 요청된 경우에만 수행한다.

## 변경 범위별 갱신 명세

문서 변경은 전체 교체, 픽셀, 레이어 구조, 이름, 레이어 속성, 선택과 프레임·시간으로 구분한다. 픽셀 변경은 자산을 공유하는 현재 프레임의 모든 레이어에 반영하고 무관한 프리뷰는 유지한다. 이름·가시성·불투명도·혼합 모드와 선택 변경은 원본 콘텐츠를 변경하지 않으므로 프리뷰를 재생성하지 않는다. 구조 변경은 기존 레이어의 프리뷰를 보존하고 추가·제거·이동한 행과 필요한 선택 행을 갱신한다.

Undo와 Redo는 원래 편집과 같은 변경 범위를 발행해야 한다. 키프레임 이동은 표시 자산이나 영상 프레임이 달라진 행만 갱신하며 전체 문서를 교체하거나 변경 범위를 특정할 수 없을 때에만 전체 갱신한다. 실패하거나 실제 변화가 없는 편집은 갱신 알림을 보내지 않는다. 타임라인의 화면에 보이는 행은 개별적으로 보유하여 다른 행의 이름이나 픽셀 변경이 그 행을 다시 준비하지 않도록 한다.

LVUI 목록의 이름과 표시 상태도 해당 행만 교체해 기존 스냅샷과 다른 행을 보존한다. 표시 중인 행의 그리기 명령은 각각 유지하며, 재생 위치만 이동할 때는 눈금과 재생선을 갱신하고 콘텐츠가 달라진 행만 다시 구성한다. iiGUI의 최종 프레임 제출 범위와 실제 지연은 별도의 실행 측정으로 확인해야 한다.

## 타임라인 눈금과 레이어 프레임

눈금의 화면 범위는 타임라인 줌을 따른다. 기본 줌에서 재생 길이가 2초보다 짧으면 2초 눈금까지 보이며, 확대할 때에도 표시 폭은 최소 두 프레임을 포함한다. 정수 프레임 경계에 눈금을 그리며 초 단위 시간 레이블, 재생선, 행의 프레임 셀과 입력 위치가 이 눈금을 공유한다. 문서 길이는 재생과 탐색 시간의 상한이다.

정적 레이어의 채워진 셀은 iiSharedCanvas Native 0.35.42의 `staticLayerTimelineRange`가 정한다. 유효한 정적 레이어는 활성 구간의 시작 프레임에 한 칸을 차지한다. 활성 범위가 생략되면 첫 칸이고, 자산이 완전히 투명한 새 Paint layer에도 이 규칙을 적용한다. 미래 프레임은 빈 안내 셀을 표시한다. 영상 레이어는 활성 구간을 칠하고 동적 레이어의 키프레임은 같은 눈금에 배치한다. 오디오 트랙의 기본 눈금 간격은 독립적인 0.25초이다.

`Congregation.independent_workspace`는 1프레임 문서에서 미래 눈금과 시간 레이블을 검증한다. 줌과 문서 길이가 바뀐 뒤에도 투명 Paint layer의 셀 폭이 프레임 하나인지 비교한다. 재생선이 활성 범위 밖에 있을 때 범위 시작에 셀 하나가 표시되고, 영상 레이어는 활성 구간을 채우는지 검사한다.

## 새 동적 레이어의 기본 길이

`New Layer`에서 Animated raster 또는 Animated vector를 생성하면 iiSharedCanvas Native 0.35.43의
`defaultDynamicLayerTimelineRange`를 사용한다. 프레임 0부터 문서의 FPS로 5초를 덮는 최소 정수
프레임 수를 배정한다. 24fps에서는 120프레임, 30fps에서는 150프레임, 25/2fps에서는 63프레임이다.

문서가 더 짧으면 새 레이어의 마지막 프레임을 포함하도록 타임라인을 늘린다. 긴 문서는 원래 길이를 유지한다.
빈 자산과 키프레임을 하나씩 만들고, 추가 키를 만들기 전까지 활성 구간에서 그 자산을 사용한다.
레이어와 타임라인 길이를 함께 저장하며 같은 Undo/Redo 항목에서 적용하고 복원한다.

타임라인은 레이어 행에 활성 프레임 범위를 그리며 실제 소수 FPS를 시간 눈금에 반영한다.
`Congregation.new_layer_integration`은 생성, 저장 후 재열기, Undo/Redo와 저장 실패 시 복원을 검증한다.
`Congregation.independent_workspace`는 소수 FPS의 셀 범위와 시간 눈금 배치를 검증한다.
