# 새 레이어 메뉴

타임라인의 New layer 드롭다운은 LVUI 컨텍스트 메뉴를 열며, 클릭만으로는
문서를 바꾸지 않는다. 메뉴의 정적 비트맵·벡터와 동적 비트맵·벡터는 각각
iiSharedCanvas의 네 아트워크 레이어 형식으로 생성한다. 비트맵은 투명하고
벡터 경로는 비어 있으며, 동적 형식에는 0프레임 콘텐츠 키가 있다.
시각 레이어가 선택된 상태에서 새 시각 레이어를 만들면 같은 아트보드에 속한다.

비디오와 조건부 레이어 항목은 선택한 `.iisc` 문서에서 처음으로 일치하는 종류를 가져오며
실제 자산과 원본 설정을 보존한다. 현재 연결된 Native 패키지는 범용 동영상
디코더를 제공하지 않는다. 오디오 항목은 빈 오디오 트랙을 만든다. 원본이 없거나 맞지 않으면
오류를 알리고 문서와 이력을 바꾸지 않는다. 사용자에게 선택받지 않은 임베딩,
비디오 프레임이나 의미 분류를 임의로 만들어 넣지 않는다.
기준 레이어가 함께 필요한 클리핑 레이어와 현재 타임라인 길이를 초과하는
키프레임은 누락하거나 잘라내지 않고 가져오기를 거부한다. 현재 가져오기는
문서 스냅샷 방식의 이력 예산이 필요하며 예산 부족 시 안전하게 거부한다.

생성은 하나의 Undo/Redo 작업이며 저장된 문서에서 형식과 자산 참조가 유지된다.
빈 레이어와 오디오 트랙의 생성 이력은 기존 문서 전체가 아닌 삽입 기록을 사용한다.
추가 취소나 실패는 기존 선택과 Redo를 보존한다. 메뉴는 마우스·터치·키보드에서
같은 뷰모델 명령을 사용하고, 화면 아래의 버튼에서는 위쪽으로 열린다.
Figma의 기준 타임라인은 `353:4887`, 메뉴 구성 예시는 `476:20612`이다.

검증은 LVUI 메뉴의 열림과 항목 연결, 네 아트워크 유형과 오디오, 원본이 필요한
유형의 유효성 검사, Undo/Redo, 저장 후 재열기 및 실패 시 롤백을 포함한다.
