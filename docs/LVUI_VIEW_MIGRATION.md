# LVUI 화면과 C++ 네이티브 표면 연결

## 계약

활성 메인 화면과 새 캔버스 창은 LVUI가 창과 화면 트리를 소유한다. 메인의
명령 막대, 두 열의 도구 레일과 상태 표시줄은 `Main.lvui`가 직접 구성하며
입력과 상태는 C++ `EditorBackend`에 연결한다. 나머지 작업 영역과 새 캔버스
선택기의 복잡한 네이티브 표면은 LVUI `NativeView`의 C++ 원천으로 연결한다.
활성 앱은 LVRS·Qt·QML 타입이나 런타임을 사용하지 않는다. 환경설정은 LVUI
컴포넌트와 `EditorBackend` 바인딩을 사용한다.

메인 작업 영역은 메인 LVUI가 소유한 같은 `EditorBackend`를 사용한다. 새 캔버스
원천은 해당 창의 `CanvasSetupModel`을 사용하며 빈 숨김 뷰를 별도로 마운트하지
않는다. `NativeView`의 자식 세대가 원천과 실제 위젯을 보유하고, 부모의 종료와
함께 입력·관찰을 퇴역시킨다. 백엔드와 원천이 서로를 강하게 소유하는 순환을
만들지 않는다. 생성 실패는 기존 창 내용을 보존하는 iiGUI의 후보 마운트 오류로
전달한다.

`ScopedWidgetMount`는 기존 앱의 위젯 ID 조회를 LVUI의 자식 세대까지 연결한다.
우선 원래 세대를 조회하고, 없으면 해당 `NativeView`의 콘텐츠 세대를 직접 조회한다.
캔버스를 찾는 일반 입력 경로에서는 전체 위젯 목록을 순회하지 않는다. 선택기의
추가 동적 세대처럼 직접 조회로 찾을 수 없는 경우에만 스냅샷에서 정확한 ID를 찾고,
같은 이름이 여러 개이면 임의의 위젯을 선택하지 않고 오류를 반환한다.

도구·캔버스·타임라인·설정 조작, 새 캔버스 크기·검색·프리셋, 메뉴·팝업, 접근성,
창 크기 변경과 닫기 동작은 이전과 동일해야 한다. 모델과 사용자 문서 데이터는
화면 구조와 독립적이다. 화면의 복잡한 C++ 구성요소가 LVUI가 제공하는 원천 경계를
통해 연결된다는 뜻이며, 모든 위젯의 기하가 `.lvui` 문장으로 다시 작성되었다는
주장은 아니다.

## 검증 기준

메인과 새 캔버스 화면의 `NativeView`가 생성된 LVUI 트리 안에 실제 콘텐츠를
마운트하는지 검사한다. 같은 백엔드로 입력이 전달되고 라이선스 전환·창 크기
변경·창 퇴역 후 재생성이 정상인지 확인한다. LVRS·Qt·QML이 활성 대상과 링크
그래프에 들어오지 않도록 정적 경계 검사와 네이티브 빌드를 수행한다.

## 선언형 전환 계약

메인 명령 막대와 도구 레일의 버튼은 기존 `EditorBackend`의 명령과 상태에
연결한다. 레일의 너비는 LVUI 아이콘 버튼의 공통 크기와 간격 토큰으로 계산하며,
선택과 빠른 마스크의 강조 표시는 해당 상태의 변화만 관찰한다. 상태 표시줄의
현재 시간은 타임라인 상태를 사용한다. 도구 레일과 명령 막대로 옮긴 색상·도형
버튼의 맥락 메뉴는 각 새 부모에 연결한다. 브러시 표본 처리, 문서 편집과
캔버스 픽셀 표면은 C++에서 수행한다.

2026-11-09 변경에서 메인 창 검사는 명령 막대의 17개 명령, 도구 레일의 46개
도구 선택, 강조 그리기, 시간 표시와 폭·표시 상태를 확인한다. 캔버스 통합
검사는 마스크·획 입력과 세 맥락 메뉴를 확인한다. 이 검사는 OS 창 없이 iiGUI
위젯 트리와 C++ 문서 엔진을 실행한 것이며 물리 펜·화면 표시 지연의 증거가 아니다.

아직 타임라인, 상세 패널과 새 캔버스 선택기 등의 위젯 배치는 C++ 원천에 남아
있다. 따라서 전체 뷰의 선언형 전환은 완료되지 않았다. 이 전환은 기존 명령의
기능을 새로 구현하거나 측정되지 않은 성능 개선을 주장하는 작업이 아니다.

## 2026-11-07 검증

- 기존 iPadOS `build/` 구성을 현재 iPhoneOS 27.2 SDK로 갱신한 뒤,
  서명을 생략한 arm64 앱 빌드가 통과했다. 기기 설치나 실행은 이 검증에 포함하지
  않았다.
- macOS에서는 기존 호환 LVUI·iiGUI 스테이지와 제품 정적 라이브러리를 사용하고
  두 창의 테스트 및 관련 화면 소스를 다시 컴파일했다. `IndependentMainWindow`와
  `IndependentCanvasSetup`은 LVUI 자식 관계, 입력·크기·기존 화면 동작 및 창 세대
  재생성을 통과했다. 실패하는 메인 표면 원천을 주입해도 기존 작업 영역이 유지되고
  바인딩 오류가 기록되는지도 확인했다. 캔버스의 직접 조회가 위젯 스냅샷을 만들지
  않고 중복 ID를 거부하며, 동적 프리셋도 조회되는 것을 검사했다. 이 검사는 OS 창을
  열지 않는 위젯 트리 검사이다.
- `lvui_native_boundary`와 네이티브 빌드 표면 검사, 스타일 토큰 검사 11개,
  패키지 디렉터리 검사 9개가 통과했다. iPadOS 링크 대상 그래프, 동적 의존성과
  공개 심볼에서 LVRS·Qt·QML 항목은 확인되지 않았다.

작업 트리의 활성 `App/`에는 QML 파일이 없다. 과거 `src/App` Qt 소스는 현재
작업 트리에서 삭제 상태이며 Git 기록에는 남아 있다. 기존 `dist/Congregation.app`은
이와 별개의 2026년 9월 버전 1.0.0 배포 산출물로 Qt·QML을 포함한다. 설치된
앱이나 새 빌드와 혼동하지 않도록 이 구형 산출물은 보존했다. LVUI 아이콘의
원저작자 고지는 라이선스 이행을 위해 유지하며, 실행 시 LVRS 라이브러리를
링크한다는 뜻은 아니다.
