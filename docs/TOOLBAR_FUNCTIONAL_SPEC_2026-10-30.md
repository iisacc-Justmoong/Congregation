# Congregation 도구 막대 기능 조사 및 구현 명세

> 제품 결정: 2026-10-31 무한 캔버스를 폐기했다. Congregation은 유한
> 캔버스만 생성하고 기존 무한 캔버스 파일은 변경 없이 열기를 거부한다.
> 아래의 무한 캔버스 관련 조사와 진행 기록은 과거 이력이다.

아래 초기 조사 결과와 기능별 명세는 조사 시점의 기준이며, 현재 구현 상태와 남은 제한은 문서 끝의 구현 진행 기록을 함께 확인한다.

조사일: 2026-10-30. 범위: 현재 작업 트리의 Native 앱에 표시되는 왼쪽 도구 레일과 그 입력 처리. 이 문서는 정적 소스 조사이며 앱·기기 실행 검증이 아니다. 기존 [SDK 기능 조사](SDK_CAPABILITY_AUDIT_2026-10-26.md)는 과거 시점의 참고 자료다. SDK에 API가 있다는 사실과 앱에서 도구가 동작한다는 사실을 구분한다.

## 판정 기준과 결과

도구 버튼은 [WorkspaceView.cpp](../App/Native/WorkspaceView.cpp) `tools()`의 47개 슬롯이다. 전경색 버튼과 스포이트가 같은 아이콘을 사용하므로 실제 도구 식별자는 46개다. [Application.cpp](../App/Native/Application.cpp) `select_native_tool()` 기준 28개는 미지원 상태 메시지만 출력한다. 나머지 18개는 액션에 연결되거나 눈금자를 토글하지만, 이 숫자가 18개 도구의 완성·실행 성공을 뜻하지는 않는다. 전경색 버튼은 색상 팝업이며 스포이트와 별개다.

| 분류 | 도구 | 현재 소스상 동작 |
| --- | --- | --- |
| 미지원 28개 | 사각·타원 선택, 올가미·다각형·자석 올가미, 마술봉, 자르기·원근 자르기, 그라디언트, 복제·패턴 스탬프, 복구·스팟 복구, 흐림·선명, 닷지·번·스펀지, 유동화·워프, 펜·곡률 펜, 앵커 추가·삭제, 다각형, 패스 텍스트, 회전 보기, 퀵 마스크 | 클릭 시 `not available ... yet` 상태 표시; 선택 또는 편집 구현 없음. |
| 연결됐으나 의미가 불완전 | Move, Direct Select, Pencil, Dry Brush, Airbrush, Mixer Brush, Bristle Brush, Smudge, Paint Bucket, Rectangle, Ellipse, Area Text, Color Picker | 아래 항목 참조. |
| 기본 경로가 존재 | Brush, Eraser, Hand, Zoom, Rulers | 마우스·펜 입력, 화면 이동·확대, 눈금자 토글 경로가 존재한다. 브러시와 지우개는 문서·레이어·예산 제한의 영향을 받으며 실제 전체 워크플로는 미검증이다. |

## 연결된 도구의 구체적인 한계

1. **Move / Direct Select**: 두 버튼 모두 같은 `Action::select`로 매핑된다. 합성 결과가 아닌 개별 표시 레이어의 알파를 히트 테스트하고, 드래그 종료 때 레이어 변환을 적용한다. Shift는 비율 확대, Alt는 회전이다. Direct Select의 경로·앵커 선택과 다중 선택은 없다. 입력: [CanvasView.cpp](../App/Native/CanvasView.cpp) `hit()`/`input()`.
2. **Pencil / Dry Brush**: 둘 다 Brush 액션이며 `apply_brush()`에서 별도 분기·재료 설정이 없다. 두 이름이 독립적인 연필 또는 마른 붓 질감을 보장하지 않는다. Airbrush, Mixer, Bristle, Smudge는 각기 엔진 플래그나 시뮬레이션 모델을 설정하지만 출력·지속 분사·색 혼합의 제품 수준 동작은 별도 검증이 필요하다. [Application.cpp](../App/Native/Application.cpp) `select_native_tool()`/`apply_brush()`.
3. **Paint Bucket**: 현재 프레임의 합성 이미지를 대상으로 허용 오차 0과 연결 영역을 이용해 마스크를 만든 뒤, 선택 레이어에 쓰는 대신 새 `Fill` 래스터 레이어를 추가한다. 64MP를 초과하면 거부한다. 참조 대상·허용 오차·연결 여부·투명도 보존·선택 영역 옵션은 연결돼 있지 않다. [Artwork.cpp](../App/Native/Artwork.cpp) `fill_at()`.
4. **Rectangle / Ellipse**: 드래그 종료 시 새 벡터 자산과 레이어를 만든다. Shift는 `filled` 인자로 전달된다. 드래그 중 경계 상자만 그리며, 기존 도형의 핸들 편집이나 명시적인 칠·선 설정은 여기서 확인되지 않는다. [CanvasView.cpp](../App/Native/CanvasView.cpp), [Artwork.cpp](../App/Native/Artwork.cpp) `shape()`.
5. **Area Text**: 클릭 위치에서 고정 1024×256 텍스트 이미지를 렌더해 새 래스터 레이어로 가져온다. 이후 문자·글꼴을 편집할 수 있는 텍스트 객체나 드래그로 정의하는 텍스트 영역은 아니다.
6. **Color Picker**: 현재 표시 프레임의 합성 결과 1픽셀을 선택하며 성공하면 내부 캔버스 도구를 Brush로 바꾼다. 원래 도구 복귀, 샘플 범위와 참조 레이어 선택은 확인되지 않는다. 내부 도구와 UI 선택 상태가 일치하는지도 통합 검사가 필요하다.
7. **상태 표시와 라이선스**: `act()`는 라이선스가 없으면 편집 액션에서 반환하지만 호출자 `select_native_tool()`은 그 뒤 선택 표시를 갱신한다. 표시와 실제 활성 도구가 달라질 가능성이 있다. 무효 선택은 이전 도구와 상태를 유지하고 이유를 알려야 한다.
8. **압력·기울기·테이퍼**: 설정 변환에 기울기·속도 반응이 있지만 캔버스 획 호출은 위치와 압력만 전달한다. `End`는 `ToolSettings::brush()`에서 소비되지 않고 Start는 브러시 크기 기반 warmup 거리로 변환된다. 사용자 결정에 따라 Start/End의 백분율은 전체 획 길이가 기준이어야 한다. [ToolSettingsBrush.cpp](../App/Native/ToolSettingsBrush.cpp), [CanvasView.cpp](../App/Native/CanvasView.cpp).

## 공통 구현 계약

- 모든 도구는 클릭·드래그·놓기·취소·포커스 상실을 일관된 세션으로 처리한다. 문서 좌표와 뷰 좌표를 분리하고, 줌·이동·회전 중에도 입력 위치가 일치해야 한다.
- 편집 가능 레이어·잠금·숨김·프레임·라이선스·경계·용량을 변경 전에 검사한다. 실패·취소 시 문서, 선택 영역, Redo 및 저장 내용이 그대로여야 한다. 선택 불가능한 기능은 선택 표시를 바꾸지 않고 명확한 사유를 표시한다.
- 하나의 사용자 동작은 하나의 Undo/Redo 항목이다. 문서 변경과 뷰 이동·확대는 구분하며, 단순 탐색은 문서 리비전·자동 저장·협업 전송을 발생시키지 않는다. 현재 대형 문서의 스냅샷 이력 한도는 [진행 기록](SDK_UPGRADE_PROGRESS.md)에 남아 있다.
- 압력, 기울기, 방위, 속도, 시간과 입력 장치 유형은 플랫폼 입력부터 엔진까지 손실 없이 전달한다. 값이 없는 장치는 명시적 기본값을 사용한다. 도구별 옵션, 상태, 커서, 단축키, 장애 및 취소 동작은 키보드·마우스·펜에서 동등하게 접근 가능해야 한다.
- 타일 단위의 미리보기와 커밋을 제공하고 경계 밖 접근을 막는다. 큰 캔버스에서는 화면 전체 버퍼·전체 스냅샷을 무조건 만들지 않는다. 저장·재열기 및 협업에서 결과와 편집 순서를 재현한다.

## 기능별 상세 명세

### P0 — 선택, 브러시 입력, 자르기, 채우기

**사각형 선택 / 타원 선택**: 드래그로 문서 좌표의 사각형·타원 마스크를 생성한다. 새로 만들기, 더하기, 빼기, 교차, 반전, 전체 해제와 경계 밖 클리핑을 지원한다. 앤티앨리어싱과 페더 반경은 명시적 옵션이다. 드래그 중 미리보기, Escape 취소, 다른 도구에 대한 마스크 전달과 저장 정책을 정의한다. 완료 조건: 각 조합 연산의 픽셀 기준 결과, 줌 상태 좌표, 경계 밖·빈 선택·Undo/Redo, 저장/재열기 및 대형 타일 경계가 통과한다.

**올가미 / 다각형 올가미 / 자석 올가미**: 자유 입력 샘플로 닫힌 경로를 생성하고, 다각형은 클릭 정점·더블 클릭 종료·마지막 점 취소를 제공한다. 자석은 명시된 반경의 이미지 에지에 경로를 스냅하고 고정점과 수동 우회를 제공한다. 기존 선택 마스크의 동일 조합 규칙을 사용한다. 완료 조건: 자체 교차·짧은 경로·화면 밖·취소·저대비 이미지 및 줌 변경에서 경로와 마스크가 결정적이다.

**마술봉 / 퀵 마스크**: 마술봉은 클릭 색상, 허용 오차, 연속/전체, 합성/현재 레이어 참조를 선택하고 결과를 선택 마스크에 반영한다. 퀵 마스크는 현재 선택을 표시 가능한 마스크로 전환해 붓·지우개로 편집하고 다시 선택으로 변환한다. 완료 조건: 투명 픽셀과 색상 경계, 연결 영역, 참조 프레임, 모드 왕복 및 취소에서 마스크가 보존된다.

**자르기 / 원근 자르기**: 사각 자르기는 조정 가능한 핸들과 비율·원점, 파괴/비파괴 옵션, 명시적 적용/취소를 제공한다. 원근 자르기는 네 모서리를 조작하고 유효한 사각형에서 변환 및 보간을 적용한다. 모든 관련 레이어, 마스크, 프레임, 문서 크기와 원점에 적용 범위를 일관되게 정의한다. 완료 조건: 비정상 사각형 거부, 투명 영역, 회전 레이어, 다중 프레임, Undo/Redo와 저장/재열기 통과.

**브러시 / 연필 / 마른 붓 / 에어브러시 / 혼합 / 강모 / 스머지 / 지우개**: 각 도구의 기본 재료와 입력 모델을 독립적으로 정의한다. 연필은 경계와 불투명 픽셀 정책, 마른 붓은 색 침착·입자, 에어브러시는 시간 기반 분사, 혼합·스머지는 기존 캔버스 샘플과 색 혼합, 강모는 개별 강모의 형태·수량을 반영한다. 지우개는 선택 마스크·레이어 잠금·알파 정책을 준수한다. Start/End 테이퍼는 전체 획 길이 비율로 적용하고 짧은 획에서 겹치는 구간 처리 규칙을 정한다. 완료 조건: 같은 입력의 재현성, 각 도구의 차별화된 픽셀 결과, 압력·기울기·시간, 취소, 프레임, 타일 경계와 대형 문서 Undo/Redo를 검증한다.

**페인트 통 / 그라디언트**: 통은 허용 오차, 연결 여부, 참조 레이어, 앤티앨리어싱, 선택 영역 및 현재 레이어/새 레이어 적용을 제공한다. 그라디언트는 시작·끝 드래그, 선형/방사형, 색상 정지점·알파·반복·혼합 모드를 제공하고 선택 영역을 따른다. 완료 조건: 투명 색상, 0 및 최대 허용 오차, 경계·타일·프레임, 적용 대상, 색상 보간 및 Undo/Redo를 픽셀 비교한다. 64MP 제한의 개선 또는 사용자에게 사전 고지는 별도 결정한다.

### P1 — 보정, 복구, 변형

**복제 스탬프 / 패턴 스탬프**: 복제는 원본 지점 지정, 정렬/비정렬 샘플과 참조 레이어를 제공한다. 패턴은 반복 타일·스케일·원점·불투명도를 제공한다. 완료 조건: 샘플 오프셋 유지, 경계 처리, 원본과 대상 겹침, 선택 영역·잠금·Undo/Redo를 검증한다.

**복구 브러시 / 스팟 복구**: 복구는 사용자가 지정한 참조를 주변 색·밝기와 자연스럽게 합성하고, 스팟은 주변에서 참조를 추정한다. 샘플 범위·브러시 크기·적용 대상을 명시한다. 완료 조건: 투명/경계 영역과 원본 부족 실패, 취소 시 무변경, 재현 가능한 픽셀 결과를 검증한다.

**흐림 / 선명 / 닷지 / 번 / 스펀지**: 흐림·선명은 반경·강도를, 닷지·번은 노출 강도와 음영 범위를, 스펀지는 채도/감도 방향과 강도를 제공한다. 색상 공간·알파·고정밀 처리 정책은 문서 프로파일과 함께 명시한다. 완료 조건: 0 강도의 무변경, 범위의 단조성, 투명 픽셀 보존, 경계·마스크·Undo/Redo를 검증한다.

**유동화 / 워프**: 기준 이미지와 비파괴 변형 필드 또는 메시를 분리하고, 브러시 크기·강도·고정 경계, 실시간 미리보기, 적용/취소와 재편집을 제공한다. 과도한 변형·뒤집힘·메모리 한도를 명시한다. 완료 조건: 미리보기 취소 시 원본 보존, 변형 재현, Undo/Redo, 큰 문서와 타일 이음새 검증.

### P1 — 벡터, 도형, 텍스트

**펜 / 곡률 펜 / 앵커 추가·삭제 / Direct Select**: 펜은 클릭·드래그로 선 및 Bézier 곡선을 만들고 닫기·종료·취소한다. 곡률 펜은 인접 점을 부드러운 곡선으로 연결한다. 앵커 추가·삭제는 해당 경로만 수정하고 Direct Select는 앵커·핸들·세그먼트를 선택·변형한다. 완료 조건: 열린/닫힌 경로, 곡선 분할, 최소 정점, 핸들 이동, Undo/Redo와 벡터 저장/재열기 검증.

**다각형 / 사각형 / 타원**: 다각형은 변 개수, 중심/경계 방식, 회전 및 정다각형 제약을 제공한다. 모든 도형은 칠·선·두께·불투명도와 드래그 미리보기를 공유하며 생성 후 벡터 속성을 수정할 수 있어야 한다. 완료 조건: 0 크기, 음수 방향 드래그, 제약 키, 편집·Undo/Redo와 저장 검증.

**영역 텍스트 / 패스 텍스트**: 텍스트는 문자열·글꼴·크기·스타일·문단·레이아웃 경계를 포함하는 편집 가능한 문서 객체로 저장한다. 영역 텍스트는 드래그 경계를, 패스 텍스트는 기준 곡선·방향·오프셋을 보존한다. 입력기 조합과 폰트 누락 대체 정책을 정의한다. 완료 조건: 한글 조합·다국어, 다시 열어 편집, 경로 수정 후 재배치, Undo/Redo와 내보내기 결과 검증.

### P2 — 화면 탐색과 보조 도구

**회전 보기**: 문서 픽셀을 수정하지 않고 화면 중심 또는 포인터 기준으로 회전한다. 각도 표시, 원점 복원, 이동·확대·펜 좌표 변환을 제공한다. 완료 조건: 회전 전후 동일 문서 해시·리비전, 좌표 역변환과 화면 복원 확인.

**Hand / Zoom / Rulers / Color Picker**: 이동과 확대의 커서 기준점과 제한, 눈금자의 원점·단위·배율 대응, 스포이트의 합성/현재 레이어 및 샘플 범위·이전 도구 복귀를 정한다. 완료 조건: 문서 무변경·리비전 보존, 경계·프레임·투명도, 활성 도구 UI와 입력 상태의 일치 확인.

## 검증 계획 및 미결 사항

1. 도구 목록의 모든 버튼에 대해 선택, 미지원 상태, 라이선스 거부 및 아이콘/실제 도구 동기화를 자동 검사한다.
2. 각 기능은 작은 결정적 픽셀/벡터 기준 자료로 시작해 취소·오류·Undo/Redo·저장/재열기·현재 프레임을 검사한다. 8K 및 타일 경계는 별도로 측정한다.
3. 디바이스별 펜 압력·기울기·시간, 장시간 분사, 접근성 및 다중 플랫폼 실행은 해당 장치에서 별도 검증한다. 이 조사에서는 수행하지 않았다.
4. 자르기의 기본 파괴 여부, 텍스트 객체 형식, 선택 마스크 저장 범위, 보정 도구의 색상 공간과 마술봉 참조 기본값은 제품 결정이 필요한 제안이다. 현재 코드에서 확정된 동작으로 간주하지 않는다.
5. 현재 기존 테스트는 [tst_canvasframe.cpp](../tests/tst_canvasframe.cpp)의 스포이트·선택·채우기 프레임 사례와 [tst_toolsettings.cpp](../tests/tst_toolsettings.cpp)의 일부 설정 변환 등을 포함한다. 검사 존재만으로 전체 도구·실제 GUI·설치본 동작을 보증하지 않는다.

아직 완성되지 않았다. 새 SDK API의 패키지 버전과 이동 설치 검증도 남아 있다.


### 선택 마스크 연결의 후속 구현

위 표는 최초 조사 시점의 상태다. 사각형·타원 드래그와 자유 올가미는 iiSharedCanvas Native
0.35.15의 마스크를 사용하며 Shift는 더하기, Alt는 빼기, 두 키는 교차다.
Select 메뉴의 Deselect와 Inverse 및 각각의 단축키는 선택 이력에 기록된다.
자유 올가미는 최대 4,096개 입력점의 닫힌 경로를 짝수·홀수 규칙으로 채우며
드래그 중 경로를 표시하고 Escape 또는 포커스 손실로 취소한다.
선택 변경은 문서 리비전, 저장 및 협업 변경을 발생시키지 않으며 선택 영역은
문서 파일에 저장하지 않는 세션 상태다. 새 문서나 열린 문서에서는 해제된다.
빈 선택은 선택 해제와 달리 모든 픽셀 편집을 차단한다.

유한 래스터의 붓·지우개는 레이어 변환을 고려해 선택 범위를 합성하며
작업 중에도 마스크된 타일을 미리 표시한다. 채우기는 선택과 영역 마스크를
곱한다. 벡터 도형은 원본을 편집 가능한 상태로 유지하면서 선택을 레이어에
연결된 래스터 마스크로 저장한다. 이때 도형의 마스크는 도형과 함께 변형되고
문서 직렬화에 포함된다. 선택 밖 획과 빈 선택에서의 채우기는 문서와 Redo를
바꾸지 않는다. 획 진행이나 종료가 실패하면 임시 획을 취소하고 문서·Redo를
보존한다. 선택 이력은 기존 문서 이력과 같은 순서로 Undo/Redo된다.

현재 선택은 최대 64MP의 조밀한 마스크이며, 선택을 적용한 획은 유한 래스터와
기존 스냅샷 이력 한도에 제한된다. 청크형·무한 캔버스, 대형 타일 기반 선택과
이력, 선택의 페더 옵션, 텍스트와 다른 미구현 도구의 마스크 연계, 자석 올가미·
마술봉·자르기·그라디언트 및 나머지 P0/P1/P2 기능은 여전히 완료되지 않았다.
선택 조작의 외부 CLI·에이전트 호출 인터페이스도 아직 연결되지 않았다.
이 문서는 단말기 실행이나 모든 플랫폼 검증을 주장하지 않는다.

### 다각형 올가미

다각형 올가미는 클릭으로 정점을 추가하고 Enter 또는 마지막 정점에서 0.4초 이내
4화면 픽셀 이내의 더블 클릭으로 닫는다. Backspace/Delete는 마지막 정점을
삭제하며 Escape, 포커스 손실, 프레임 또는 도구 변경은 미완성 경로를 취소한다.
첫 클릭의 Shift/Alt 조합이 마스크 결합 방식을 결정하고 자유 올가미와 같은
4,096점 및 선택 마스크 한도를 적용한다. 확정은 선택 이력 한 항목이며
미완성 경로와 취소는 문서 리비전이나 Redo를 변경하지 않는다.

### 마술봉 기본 선택

마술봉 클릭은 현재 프레임의 합성 이미지를 기준으로 동일한 premultiplied RGBA의
상하좌우 연결 영역을 선택한다. Shift는 더하기, Alt는 빼기, 두 키는 교차이며
선택 이력에 기록된다. 투명 픽셀의 숨겨진 RGB는 무시한다. 현재 앱의 기본값은
허용 오차 0과 연속 모드다. SDK API는 허용 오차와 전체 영역 모드를 지원하지만
앱 Tool 패널에서 0–100% 허용 오차, 연속 여부와 현재 레이어 참조를 조작한다.
현재 레이어 참조는 현재 프레임에서 해당 레이어의 공간 픽셀을 사용하며,
숨겨졌거나 공간 픽셀이 없는 레이어는 선택을 바꾸지 않고 오류를 표시한다.
유한 캔버스의 64MP 상한과 세션 선택 이력의 제한도 그대로 적용된다.

### 펜 입력 전달

캔버스 입력의 위치, 압력, 기울기와 펜 회전, 측정된 이벤트 간격을
iiSharedCanvas의 획 샘플로 전달한다. 기울기는 iiGUI의 각도 범위 ±90도를
엔진의 ±1로, 회전은 도에서 라디안으로 변환한다. 측정 시각이 없거나
역행하는 입력의 간격에는 기존 1/120초 기본값을 적용한다. 이전 위치·압력
호출도 기존 고정 간격으로 계속 지원한다. 기울기와 시간은 브러시 엔진에서
해당 동역학 또는 분사가 활성화된 경우 픽셀에 반영된다. UI의 모든 도구가
차별화된 재료 모델을 갖추거나 전체 획 길이 기준 Start/End 테이퍼를
구현한 것은 아니며, 디바이스별 실제 입력은 별도 검증이 필요하다.

Tool 패널의 구성과 선택 전환은 운영체제 창을 열지 않는 위젯 트리 테스트로
검사한다. 이 선택적 테스트는 `CONGREGATION_IIGUI_TEST_HEADERS`로 연결한 iiGUI
라이브러리 버전과 일치하는 내부 위젯 테스트 헤더의 루트 경로를 지정해야 한다.
프로덕션 코드는 iiGUI 공개 API만 사용한다.
실제 화면 레이아웃과 장치 입력을 실행 검증한 것은 아니다.

### 이동 중 브러시의 속도 반응

위치·시간으로 계산한 획 속도는 문서 픽셀/초 단위다. Tool 패널의 Velocity
백분율을 이 원시 속도에 직접 곱하면 기본 10%에서도 이동 중 불투명도가 0이
된다. 실시간 미리보기와 전체 획 테이퍼 재생 모두 iiBrushTools가 제공하는
정규화 속도 바인딩을 사용한다. 기본 기준 속도 1,200 문서 px/s 이상에서
설정된 백분율만큼 불투명도가 감소하고, 0%는 속도에 영향을 받지 않는다.
압력에 따른 크기·흐름과 산포, 선택 마스크 및 획 단위 이력은 별도 설정으로
유지한다. 회귀 테스트는 기본 설정으로 빠르게 꺾어 그린 획의 진행 중 픽셀과
완료 픽셀, 필압·산포 차이, Undo/Redo를 확인한다. 실제 창과 펜 기기에서의
실행 검증은 포함하지 않는다.

### 그라디언트 기본 적용

그라디언트는 드래그 시작점에서 현재 전경색을 사용하고 끝점에서 투명해지는
선형 래스터를 생성해 현재 프레임에만 표시되는 새 레이어로 추가한다. 선택
마스크는 색상과 알파에 적용되며 적용은 한 번의 Undo/Redo 항목이다. 길이가
0인 드래그와 투명한 결과는 문서와 Redo를 바꾸지 않는다. 드래그 중 선을
미리 표시하고 취소할 수 있다. Tool 패널에서 선형/방사형과 반복을 전환하고,
최대 256개의 정지점을 추가·선택·삭제하며 위치, 현재 색상과 불투명도를
조작한다. 시작색은 직접 지정하기 전까지 현재 전경색을 따른다. 새 레이어의
블렌드는 Normal, Multiply, Screen, Overlay 중에서 고른다. 큰 타일 캔버스와
다른 블렌드 모드의 선택 UI는 아직 구현되지 않았다.

### 페인트 통 옵션

페인트 통은 Tool 패널에서 허용 오차, 상하좌우 연결 영역 여부와 합성 또는
현재 레이어 참조를 선택한다. RGBA의 premultiplied 색과 알파 차이를 비교하고
숨겨진 참조 레이어는 오류로 거부한다. 선택 마스크를 반영한 결과는 현재
프레임에만 보이는 새 래스터 레이어로 추가하며, 빈 결과와 오류는 문서 및
Redo를 바꾸지 않는다. 이력 예산을 초과하는 적용도 거부한다. 정적 비트맵
레이어에 직접 적용하거나 기존 알파를 보존할 수도 있으며, 공유된 래스터 자산은
복제해 다른 레이어가 바뀌지 않도록 한다. 변형된 레이어의 픽셀은 표시 프레임의
문서 좌표를 통해 선택 마스크와 대조한다. 직접 적용은 정적·동적 비트맵의 현재
프레임에 한정되며, 경계 앤티앨리어싱도 선택할 수 있다. 64MP를 넘는 타일형
처리는 아직 구현되지 않았다.


### 퀵 마스크

도구 모음의 퀵 마스크 버튼으로 세션에 진입하고 다시 누르면 선택에 적용한다.
선택 밖은 반투명 빨강으로 표시하며, 브러시는 선택을 빼고 지우개는 복원한다.
현재 선택이 없으면 전체가 선택된 상태에서 시작한다. 획을 그리는 도중에도
마스크가 표시되며 임시 모드의 Undo/Redo는 마스크 획만 대상으로 한다. 적용은
기존 선택 이력 한 항목으로 기록하고 변경이 없는 적용은 선택과 Redo를 보존한다.
Escape 또는 프레임 변경은 임시 편집을 취소한다. 포커스 손실은 진행 중인
획만 취소하고 모드를 유지해 툴 패널을 계속 사용할 수 있다. 메뉴 기반 문서
편집과 캔버스 드롭은 모드가 끝날 때까지 차단한다. 레이어 패널과 협업 변경은
별도 경로로 들어올 수 있다. 선택은 문서가 아닌 세션 상태다.

64MP 이하 유한 캔버스는 조밀 마스크를 사용하며, 더 큰 유한 캔버스와 무한
캔버스의 현재 할당 영역은 iiSharedCanvas의 타일 마스크 편집기를 사용한다.
산포·대칭 등 브러시 엔진 설정과 획 단위 임시 Undo/Redo를 유지하며, 적용 시
하나의 선택 이력으로 기록한다. 편집 중 문서 또는 선택이 변경되면 적용을
거부해 새로운 상태를 보존한다. 타일 편집의 작업·이력 예산은 64MiB다.
오버레이는 뷰 크기에 따라 최대 2048×2048 샘플로 계산하며 캐시는 없다.
핵심 편집과 이력은 창을 열지 않는 테스트로 검증하며 실제 UI 또는 기기 실행을
검증한 것은 아니다.


### 선택 경계 옵션

사각형·타원 선택, 올가미와 마술봉의 Tool 패널에서 안티앨리어싱을
켜고 끄고, 0–32px 페더 반경을 조절한다. 기존 경로를 래스터화한 뒤
iiSharedCanvas의 분리된 `featherMask`로 경계를 흐리고, 그 결과를 기존
선택에 더하기·빼기·교차한다. Undo/Redo는 최종 선택 변경 한 항목이며
문서 리비전은 바꾸지 않는다. 공개 앱 API는 0–256px을 허용하고 비정상
값을 변경 없이 거부한다. 타일 마스크의 페더는 계산 영역과 이력 예산을
따른다. 실제 UI와 기기 실행 검증은 포함하지 않는다.


### 강모와 스머지 연결

강모 도구는 iiBrushTools가 생성한 수량별 팁을 사용하고, 스머지는 Mix 값을
스머지 강도로 전달해 현재 래스터에서 색을 끌어온다. 스머지는 기본적으로
전경색을 추가하지 않는다. 선택 마스크와 기존 획 미리보기·Undo/Redo가 적용된다.
믹서와 에어브러시의 기존 엔진 설정도 같은 도구 설정 API에서 만든다. 이 변경은
연필·마른 붓의 고유 재료, 전체 획 길이 기준 Start/End 테이퍼 또는 대형 타일
캔버스의 모든 동작을 완성했다는 의미는 아니다. 실제 펜 기기 실행 검증은 없다.


### 연필과 마른 붓의 기본 재료

연필은 iiPaintEngine의 Hard Mix 마스크로 팁 경계를 이진화한다. 불투명도와
흐름이 100%이고 선택 마스크가 완전히 선택된 픽셀에서는 불투명 픽셀로
그린다. 불투명도·흐름 또는 부분 선택이 낮으면 결과 알파도 낮아질 수 있다.
마른 붓은 문서 좌표의 반복되는 4×4 종이 입자로 색 침착을 조절한다. 두
도구는 선택 마스크와 획 Undo/Redo를 따르며, 보다 풍부한 사용자 지정
입자·재료와 실제 펜 입력 검증은 남아 있다.


### 자석 올가미

자석 올가미는 현재 프레임의 합성 이미지를 참조해 클릭한 고정점 사이를
iiSharedCanvas의 경계 추적으로 연결한다. 도구 패널에서 화면 픽셀 기준
탐색 반경을 지정하며, 확대율에 맞춰 문서 픽셀로 변환한 뒤 1–64px로 제한한다.
반경은 고정점 주변의 경계 선택과 탐색 사각형의 확장에 사용한다. 포인터 이동은
다음 경로를 미리 표시하고 클릭은 고정한다. Enter 또는 마지막 위치에서의
더블 클릭은 닫아 선택하며 Backspace는 마지막 고정점을 제거한다. Control
또는 Command를 누른 클릭은 수동 직선으로 우회한다. Shift/Alt 결합, 선택
페더와 안티앨리어싱, 선택 Undo/Redo를 공유한다. Escape, 포커스 손실, 프레임
변경은 임시 경로를 취소한다. 참조 문서의 변경은 다음 입력이나 적용 때 감지해
경로를 취소하며 선택만으로 문서 리비전은 바뀌지 않는다.
경계 신호가 없는 영역은 직선으로 연결한다. 참조는 유한 캔버스 64MP 이하,
한 구간의 동기 탐색은 131,072픽셀, 전체 경로는 4,096점으로 제한된다.
제한을 넘으면 고정점을 더 가까이 추가해야 한다. 큰 캔버스의 타일 기반
비동기 추적과 실제 화면·기기 검증은 남아 있다.


### 비파괴 사각 자르기

자르기 도구에서 사각형을 드래그하고 모서리를 조정하거나 내부를 끌어 이동한다.
Tool 패널은 자유·1:1·4:3·16:9 비율과 적용/취소를 제공하며 Enter와 Escape도
동작한다. 적용은 유한 캔버스의 경계 안에서 전체 프레임을 재구성한다. 원본
래스터·벡터 자산은 유지하고 레이어와 아트보드의 위치 및 비연결 마스크를
맞춘다. 기존 선택 마스크도 새 캔버스에 맞게 잘리며 문서와 선택은 함께 한
번의 Undo/Redo로 복원된다. 미리보기, 취소, 잘못된 영역과 예산 초과는 문서와
Redo를 변경하지 않는다. 정수 픽셀 경계로 확정하며 참조 문서 변경은 다음
입력 또는 적용 때 감지해 취소한다.

현재는 비파괴 사각 재구성만 지원한다. 파괴적 픽셀 삭제, 원근 자르기, 무한
캔버스, 원점 이동 시 Dissolve 레이어, 화면·기기 실행 검증은 미완료다. 비율은
새 드래그나 모서리 조정에 적용되며 픽셀 반올림으로 한 픽셀 차이가 날 수 있다.

### 전체 획 길이 테이퍼의 유한 캔버스 연결

유한 비트맵 레이어의 브러시와 지우개는 획 시작 픽셀과 입력 표본을 임시로 보존하고,
종료 시 전체 경로 길이를 기준으로 Start/End 비율을 적용한다. 두 구간이 겹치면 더
작은 크기 비율을 사용하고, 길이가 0인 점은 테이퍼하지 않는다. 최종 픽셀은 기존 선택
마스크와 합성한 뒤 하나의 문서 이력으로 확정하며 취소와 실패는 획 시작 상태를
복원한다. 압력·기울기·회전·시간과 브러시의 실제 재료 상태를 재사용한다.

스트리밍 중 화면에는 기존 획 미리보기가 표시되며 종료 시 전체 길이를 적용한 최종
결과로 교체된다. 입력은 최대 65,536점과 SDK 렌더 예산 및 64 MiB 문서 이력 예산을
따른다. 현재 무한/청크 캔버스는 테이퍼를 적용하지 않고 상태 메시지를 표시한다.
원본 타일의 점진적 동결, 비동기 실시간 테이퍼 미리보기와 대형 문서의 이력은 남았다.

### 페인트 통의 경계 앤티앨리어싱

도구 패널에서 경계 앤티앨리어싱을 켜면 기존 연속/전체 색상 판정의 이진 결과를
4×4 서브픽셀의 0.5 등고선으로 재구성한 다음 선택 마스크와 결합한다. 이 옵션은
기본적으로 꺼져 있어 기존 채우기의 픽셀 결과를 유지한다. 직접 레이어 편집과 새
레이어 모두 같은 커버리지를 적용하고 각 결과는 하나의 Undo/Redo 항목이다. 이는
이미 래스터화된 경계를 근사하는 기능이며 원래 벡터 윤곽을 복원하지 않는다.

### 프레임별 비트맵 직접 편집

정적 비트맵이 여러 프레임에서 보이는 경우 붓·지우개 또는 직접 채우기는 현재
프레임에만 새 비트맵을 만들고 키프레임 소스로 전환한다. 기존 에셋의 참조가 다른
레이어나 마스크에 남아 있으면 그대로 보존한다. 동적 비트맵도 현재 프레임의 새
에셋으로 편집하고 다음 프레임에 기존 홀드 내용을 복원해 다른 프레임을 바꾸지 않는다.
선택 마스크와 전체 획 테이퍼를 적용하며, 한 편집은 하나의 문서 이력 항목이다.
변경 없는 획과 취소는 임시 에셋·키프레임을 버리고 Redo를 유지한다. 현재 이 경로는
유한 래스터 에셋에 한정되며 청크 및 무한 캔버스의 프레임별 복사는 지원하지 않는다.

### 원근 자르기

원근 자르기는 사각형을 드래그해 시작한 뒤 네 모서리를 개별 조정하고, 안쪽을
드래그해 이동한다. 적용·Enter는 네 점이 문서 안의 유효한 볼록 사각형인 경우 각
레이어와 프레임을 같은 원근 변환으로 재구성한다. 선택 마스크도 변환하며 한 번의
Undo/Redo로 문서와 선택을 함께 되돌린다. 패널에서 출력 가로세로 비율을 선택할 수 있다.

이 적용은 래스터 변환이다. 벡터 경로·레이어 마스크·필터와 위치 애니메이션은 각
프레임의 레이어 픽셀에 반영되므로 적용 후 원래 속성으로 편집할 수 없다. 레이어
순서·이름·보임·합성·불투명도 애니메이션과 오디오는 유지한다. 기본 작업량 상한은
입력과 출력 각각 4MP, 출력 전체 16MP, 64개 레이어·프레임과 64MiB 이력 예산이다.
무한 캔버스, 아트보드, Dissolve 또는 비화상 제어 레이어는 변경 전에 거부한다.
처리는 정규화된 sRGB와 이중선형 보간을 사용하며 저장 전 원본 데이터는 Undo로
복원할 수 있다. 큰 문서의 타일 처리와 편집 가능한 비파괴 원근 변환은 남았다.


### 사각 자르기의 픽셀 삭제 옵션

사각 자르기는 기본적으로 캔버스 경계와 좌표만 바꾸는 `Keep cropped pixels` 모드다.
`Delete cropped pixels`를 선택하면 적용 시 각 프레임의 각 레이어를 사각 경계로
래스터화하고, 그 과정에서 교체된 원본과 마스크 중 더 이상 참조되지 않는 자산을
문서에서 제거한다. 화면에 사용하지 않던 별도의 자산은 임의로 삭제하지 않는다.
선택 마스크도 함께 잘리고 한 번의 Undo/Redo로 복원된다. Undo를 위해 이전 원본은
현재 세션의 이력에 남을 수 있으므로 보안 삭제 수단이 아니다. 벡터 편집 정보와
변형·필터·마스크는 결과 픽셀에 적용되므로 패널에 래스터화 사실을 표시한다.

원근 자르기와 같은 유한 캔버스·최대 4MP 입력/출력·64개 레이어·64프레임 및
총 출력 16MP 예산이 적용된다. 아트보드, Dissolve 및 비공간/비디오 레이어는
거부하며 실패와 취소는 문서 및 Redo를 유지한다. 타일형 대용량 처리, 비파괴
원근 편집과 남은 P0/P1/P2 도구는 아직 구현되지 않았다.


### 에어브러시의 시간 기반 분사

에어브러시 획을 누르고 있는 동안 iiSDK UI 이벤트 루프가 약 33ms마다 마지막
위치·압력·기울기·회전을 이용해 시간 표본을 전달하므로 포인터가 정지해도
미리보기에서 분사가 누적된다. 실제 입력 시각과 타이머의 단조 시간을 한 획의
공통 시간으로 결합해 중복 분사를 피한다. 포인터를 놓거나 획을 취소하고 도구·
프레임·포커스가 바뀌면 타이머가 정리된다. 스케줄러가 분사를 처리하지 못하면
상태 메시지를 표시하며 정상적인 입력·놓기 경로는 계속 사용할 수 있다.
선택 마스크와 퀵 마스크, 전체 획 테이퍼 및 하나의 Undo/Redo 항목을 따른다.
라이선스가 중간에 무효화되면 진행 중인 획을 취소한다. 실제 펜과 기기별 화면
실행 검증은 별도이며 무한·대형 문서의 선택과 이력 제한은 그대로다.


### 문서 편집과 획의 이력 예산

편집 전후의 문서와 선택 전환을 한 이력 항목으로 보존할 수 없는 경우, 문서
저장 전에 작업을 거부하고 이전 문서·선택·Redo를 유지한다. 기존처럼 이력 없이
편집을 적용하거나 기존 Undo 스택을 지우지 않는다. 저작 정보가 포함된 최종
문서 상태를 저장 전에 직렬화해 확인한다. `Artwork` 생성자는 테스트나 다른
호스트가 이력 바이트 예산을 지정할 수 있으며 기본값은 64MiB다. 일반 문서 스냅샷 하나는 그 절반 이하여야 한다. 예외로 무한 캔버스의
청크 레이어 일반 붓·지우개 획은 선택 유무와 이동·확대·회전 여부에 관계없이 변경 타일만
별도의 비트맵 이력 명령으로 보관하므로 문서 전체가 스냅샷 한도를 넘더라도
편집할 수 있다. iiSharedCanvas Native 0.35.34의 실제 픽셀 변경 경계를 사용하며,
선택이 있으면 0이 아닌 선택 경계와 교차하는 타일만 검사한다. 선택 없는 획은 iiSharedCanvas Native 0.35.35의 획 확장 모드를 사용하며
무한 캔버스를 확장한 경우 원점과 크기도 픽셀과 함께 Undo/Redo한다. 선택 변경과 이 명령은 같은 Undo/Redo 순서를 사용하며, 미리보기와
최종 픽셀에 선택을 적용한다. 한 획은 최대 1,024개 타일과 설정된 이력 예산으로
제한하며, 예산 초과·취소·저장 실패 시 문서와 Redo를 보존한다. 현재 타일 이력
경로는 전체 획 길이 기준 테이퍼를 iiBrushTools로 재생한다. 무한 캔버스의 청크를 직접 채울 때도
선택·참조 영역에서 변한 픽셀만 같은 타일 이력에 기록한다. 변환된 레이어와
선택이 없는 채우기에도 적용하며, 작업 영역이나 이력 예산을 넘으면 픽셀과
Redo를 보존한다. 공유·다중 프레임 편집에서는 프레임별 자산 연결도 같은 항목에 기록한다.
저장 계층의 문서 처리 및 그 밖의 대형 문서 도구 이력은 여전히 별도 개선이 필요하다.


### 대형·무한 캔버스의 타일 사각·타원·올가미 선택

iiSharedCanvas Native 0.35.31의 불변 타일 마스크를 이용해 64MP를 넘는 유한
캔버스와 무한 캔버스의 현재 할당 영역에서 사각·타원·자유/다각형 올가미 선택과 페더를 지원한다.
페더는 선택 주변 계산 영역이 16MP를 넘으면 거부하며 균일한 전체 선택은
추가 버퍼 없이 유지한다.
더하기·빼기·교차·반전·해제와 선택 Undo/Redo는 일반 선택과 같은 순서이며
선택만 바꿀 때 문서 리비전과 저장 파일은 바뀌지 않는다. 같은 선택을 다시
적용하면 Redo가 유지된다. 화면 경계는 현재 보이는 영역만 샘플링한다.

유한 비트맵 레이어의 붓·지우개는 타일 선택을 미리보기와 최종 픽셀에 적용한다.
현재 레이어를 참조하는 채우기는 현재 레이어 또는 새 레이어에 적용할 수 있다.
변환된 경계와 투명 연결 후광만 렌더해 선택과 결합하며, 새 레이어는 선택의
0이 아닌 범위만 저장하고 64MP와 이력 바이트 예산의 1/8 픽셀 한도를 따른다. 이 채우기는 레이어
필터가 없고 기준점이 해당 참조 영역에 있어야 한다. 두 편집 모두 기존 64MiB
문서 이력과 래스터 작업 예산을 따르며, 현재 프레임의 복사·Undo/Redo를 지원한다.
무한 캔버스의 획과 지우개는 선택 유무에 관계없이 변환 없는 청크 레이어에서
공유 자산이나 여러 프레임을 편집할 때 현재 프레임의 청크 자산을 복사해 다른
레이어·프레임을 보존한다. 전체 획 길이 기준의 테이퍼는 원본 청크로 재생하며,
결과가 바뀌지 않는 획은 Redo를 보존한다.
선택은 현재 할당 영역 안으로 제한된다. 획 중 실제로 변경된 각 타일 전체에
원본 픽셀과 선택 마스크를 합성해 선택 밖의 임시 획이 보이지 않도록 한다.
이동·확대·회전된 레이어도 같은 선택 경계를 따른다. 최대 1,024개 타일까지
미리 표시하며, 이를 넘으면 확정된 기존 이미지를 표시하고
적용 후 결과가 나타난다. 스냅샷 이력에 들어가지 않는 비공유 단일 프레임 획에는 위의
타일 이력 경로를 사용한다. 공유 및 다중 프레임 청크의 현재 레이어 획과 직접
채우기도 변경 타일과 프레임별 자산 연결을 함께 기록한다.
비파괴 사각 자르기는 타일 선택을 잘라 새 캔버스 원점으로 옮긴다. 결과가
64MP 이하면 조밀 마스크로 전환하고, 더 크면 희소 타일과 암묵적 배경을
유지한다. 부분 자르기가 표현된 타일에서 16MP를 넘게 검사해야 하거나 문서·선택
이력 예산을 넘으면 변경 없이 거부한다. 크기와 선택은 하나의 Undo/Redo 항목이다.
대형 유한 문서의 원근 크롭과 파괴적 사각 크롭은 사각형 주변에서 각 레이어의 표시 결과를
프레임마다 최대 4MP로 렌더한 뒤 보간하며 선택도 같은 변환을 적용한다.
출력 한도는 4MP, 전체 출력은 16MP이고 레이어와 프레임은 각각 최대 64개다.
작업 영역·문서 이력 예산 초과, 4MP를 넘는 필터 원본, 아트보드 등 미지원 콘텐츠는 변경 없이 거부한다.
선택 영역의 선형·방사형 그라디언트는 0이 아닌 범위만 래스터화하며,
선택 영역이 64MP 또는 이력 바이트 예산의 1/8 픽셀을 넘으면 거부한다.
무한 캔버스에 선택이 없으면 현재 할당 영역에만 그라디언트를 적용한다. 같은
작업·이력 예산을 따르고 할당 영역을 넘겨 새로 확장하지 않는다. 결과는 현재
프레임에만 표시되며 Undo/Redo와 저장·재열기를 지원한다.
이동·확대·회전된 청크의 획과 지우개도 문서 좌표의 선택 영역을 적용하며,
획 중 미리보기·취소와 전체 획 테이퍼를 지원한다. 변환된 획은 현재 할당된
문서 영역으로 제한하고 캔버스를 자동 확장하지 않는다.
대형·무한 캔버스의 할당 영역에서 마술봉과 채우기는 현재 래스터 또는 합성 참조를
지원한다. 합성 참조는 보이는 필터 없는 래스터·청크 비트맵 레이어들의 경계를
합쳐 최대 64MP만 렌더한다. 아트보드, 필터와 비트맵이 아닌 레이어는 거부한다.
현재 레이어 또는 새 레이어 채우기는 선택이 없는 경우에도 사용하며, 결과가
작업·이력 예산을 넘으면 변경 없이 거부한다. 투명한 색상의 채우기는 영역을
할당하지 않는 무변경 작업이며 Redo를 보존한다. 연결 영역이 바깥에서 분리되는
경우에는 잘못 합치지 않고 거부한다. 무한 캔버스의 현재 청크 레이어 직접
채우기는 레이어의 이동·확대·회전을 로컬 픽셀 좌표로 변환해 적용하며 현재
프레임의 청크를 복사해 다른 프레임과 공유 레이어를 보존한다. 선택·알파 보존과
작업·이력 예산을 따르며, 결과 로컬 영역은 iiSharedCanvas 0.35.32의 좌표 한도와
메모리 예산 안이어야 한다. 현재 할당 영역 밖의 마술봉은 아직 없다. 대형·무한 캔버스 자석 올가미는 각 구간
주변의 합성 이미지를 최대 1MP로 렌더하고 최대 131,072 픽셀을 탐색한다.
너무 먼 구간은 거부하며 수동 고정점으로 나눌 수 있다. 참조가 바뀌면 취소한다.
할당 영역 밖 무한 선택은 아직 없다.
기존 64MP 이하 유한 캔버스의 조밀 마스크 편집은 기존 동작을 유지한다.
이 상태는 요청된 대형 캔버스 도구 연결의 완료가 아니며 실제 창·기기 실행도
검증하지 않았다.

### 타일 선택과 벡터 도형

대형 유한 캔버스와 무한 캔버스의 타일 선택은 도형의 보수적 경계와 교차하는
영역만 래스터 마스크로 구체화해 벡터 레이어에 연결한다. 도형을 이동하면
마스크도 함께 이동하며 저장·재열기와 문서 및 선택의 Undo/Redo를 지원한다.
도형의 보수적 경계가 선택과 겹치지 않으면 무변경으로 처리하고 Redo를 보존한다. 마스크는 최대 64MP와
이력 예산의 1/8 픽셀 한도를 적용하며 초과 시 문서를 변경하지 않는다.

### 공유 청크와 다중 프레임의 타일 이력

스냅샷 예산에 들어가지 않는 무한 캔버스 청크 문서에서 공유 레이어 또는 여러
프레임의 현재 레이어를 획·지우개·직접 채우기로 편집할 때, 변경된 타일과
프레임별 자산 연결을 한 이력 항목으로 기록한다. 이전 자산이 다른 참조를
가지면 그대로 두며 참조가 없는 경우 Undo 때 원본을 복원한다. 선택 이력과
문서 이력의 순서를 지키고, 실패·취소·무변경은 문서와 Redo를 보존한다.
타일과 연결 정보가 이력 예산을 넘으면 변경을 거부한다. 편집 중에는 프레임
격리를 위해 청크 자산을 복사하므로 작업 메모리와 저장 비용은 여전히 자산
크기에 비례하며, 래스터가 아닌 자료와 다른 편집 명령의 이력까지 대체하지는 않는다.

### 마술봉 경계 옵션

마술봉 Tool 패널은 다른 선택 도구와 같은 앤티앨리어싱 체크박스와 0–32px
페더 슬라이더를 제공한다. 결과 이진 마스크에 먼저 앤티앨리어싱을 적용하고
페더 처리한 뒤 기존 선택과 결합하며, 이 변화는 선택 이력 한 항목이다.
조밀 및 타일 선택 모두 적용하며, 타일 페더가 작업 예산을 초과하거나 옵션이
유효하지 않으면 기존 선택과 Redo를 보존한다. 기존 `set_wand_selection` 호출의
기본값은 이진·페더 없음이고 명시적 옵션은 0–256px 페더를 허용한다. 화면은
공유 선택 설정을 사용하므로 초기 앤티앨리어싱이 켜져 있다.

### 대형 문서의 래스터 레이어 생성 이력

그라디언트와 타일 선택·대형 캔버스의 새 레이어 채우기는 생성한 래스터 자산,
레이어 위치와 현재 프레임 정보만 한 이력 항목으로 보관한다. 기존 문서 전체를
이력에 복제하지 않으며, 다른 편집을 되돌린 다음 같은 자산과 레이어 순서를
복원한다. 선택 변경은 별도 이력으로 같은 순서에 참여한다. 이력 예산을 넘거나
저장에 실패하면 문서와 Redo를 보존한다. 생성한 래스터 자체의 메모리와 저장
비용은 남으며, 다른 문서 편집과 벡터 레이어 생성의 스냅샷 한도까지 대체하지는 않는다.


### 다각형 벡터 도구

도구 막대의 다각형은 드래그로 현재 프레임에 닫힌 벡터 도형을 생성한다.
Tool 패널에서 3–64개 변, 회전, 중심 기준 생성, 칠과 외곽선, 선 두께와
불투명도를 설정하며 Shift는 가로·세로를 같은 크기로 제한한다. 역방향
드래그도 지원하고 작업 중 경로를 미리 표시한다. 생성은 선택 마스크를 따르며
Undo/Redo, 파일 저장과 다시 열기를 지원한다. 잘못된 설정이나 크기가 없는
도형은 문서와 Redo를 보존한다. 칠과 외곽선은 현재 전경색을 공유한다.
생성 후 앵커와 개별 칠·선 속성 편집은 아직 없으며, 벡터 생성은 기존 문서
스냅샷 이력 예산에 제한된다. 사각형·타원의 공통 옵션과 나머지 P1 도구도
별도 구현이 필요하다. 이 기능은 헤드리스 통합 검사 범위에서 검증했다.


### 유한 캔버스로 제품 범위 변경

Congregation은 유한 크기 캔버스만 생성한다. 무한 생성 요청과 협업의 무한
생성·영역 확장 명령과 무한 문서 협업 스냅샷은 거부하며, 기존 무한 문서를 열 때 원본 파일과 현재
문서, 선택 및 Undo/Redo는 변경하지 않는다. 유한 문서의 열기·저장과 기존
타일 선택은 계속 지원한다. iiSharedCanvas의 범용 타일 자료구조는 다른
제품과 유한 대형 문서에도 사용되므로 제거하지 않았다. 기존 내부의 무한
문서 처리 코드는 SDK 자료 형식 검증을 위해 남아 있으나 제품에서 생성하거나
열 수 있는 기능은 아니다. 무한 문서 사용자에게 자동 변환은 제공하지 않는다.
iiSharedCanvas Native 0.35.36을 사용해 64MP를 넘는 새 유한 캔버스와 새
레이어는 256px 청크로 생성한다. 유한 청크의 붓·지우개·선택 미리보기와
현재 레이어 채우기는 조밀 또는 타일 선택을 따르며 캔버스 바깥으로 확장하지
않는다. 공유 자산과 다중 프레임은 현재 프레임을 격리하며, 스냅샷이 예산을
넘는 경우 변경된 타일 중심의 이력을 사용한다. 이력 예산 초과·취소·저장 실패는
기존 문서와 Redo를 보존한다. 공유 프레임을 편집하는 동안 자산 복사 비용은
남아 있다. 맨 아래의 단색 불투명 바탕 위 비트맵의 합성 참조를 지원하며, 다른 벡터
내용·효과는 명시적으로 거부한다. 채우기와 그라디언트의 구체화 영역은 최대
64MP와 작업·이력 예산에 제한된다. 기존 큰 일반 래스터 자산이 자동으로 청크로
변환되지는 않는다. 유한 청크 문서는 구버전 iiSharedCanvas에서 검증 실패하므로
소비자는 0.35.36 이상을 사용해야 한다.

### 다각형의 0px 외곽선과 과거 형식 회귀

다각형에서 외곽선 두께가 0이면 외곽선을 만들지 않는다. 칠이 켜져 있으면
채워진 도형을 생성하며, 칠 없이 0px 외곽선만 지정하면 보이는 도형이 없어
문서와 Redo를 변경하지 않고 거부한다. 선택 마스크 및 생성 이력 규칙은 같다.
무한 캔버스 폐기 전용 회귀 자료는 제품 열기의 거부를 확인한 다음 SDK 형식으로만
복원해 내부 이력과 직렬화를 검사한다. 유한 문서의 실제 열기 검사는 별도로 유지한다.

### 그라디언트 정지점 추가

새 정지점은 가장 넓은 구간의 중간에 추가하며, iiSharedCanvas 렌더러와 같은
premultiplied-alpha 보간으로 중간 색상과 불투명도를 계산한다. 따라서 정지점을
추가하는 것만으로 그 지점의 기존 색상이 변하지 않는다. 값은 8비트 색상으로
저장하므로 주변 보간 결과에는 양자화 오차가 있을 수 있다.

### 넓은 선택 안의 제한된 채우기

대형 유한 캔버스의 새 레이어 채우기는 선택 경계와 참조 색상으로 찾은 채우기
경계의 교집합만 구체화한다. 선택 영역이 64MP를 넘더라도 실제 교집합이 작업과
이력 예산 이내라면 채울 수 있다. 교집합이 비어 있으면 문서와 Redo를 그대로
보존한다. 교집합 자체가 예산을 초과하면 이전처럼 변경 없이 거부한다.

### 분산된 선택 영역의 희소 그라디언트

iiSharedCanvas Native 0.35.37의 마스크 영역 순회를 이용해, 전체 경계 사각형이
64MP 또는 기존 구체화 예산보다 큰 타일 선택에서도 실제 선택된 64px 영역만
그라디언트와 마스크로 처리한다. 결과가 있는 영역은 유한 문서의 256px 청크
자산으로 합치며 현재 프레임에 표시되는 새 레이어로 생성한다. 선택의 부분 알파,
그라디언트 알파·반복·블렌드와 Undo/Redo, 저장·재열기를 유지한다. 투명 결과는
무변경이며 Redo를 보존한다. 결과 청크 또는 영역 수가 작업·이력 한도를 넘으면
문서를 변경하지 않고 거부한다. 선택이 없는 전체 대형 그라디언트와 큰 선택을
모두 채우는 경우는 여전히 예산 한도의 영향을 받는다. 기존 청크 문서 형식은
0.35.36부터 읽을 수 있지만 이 앱을 빌드하려면 0.35.37 이상이 필요하다.

### 분산 선택과 참조의 희소 채우기

새 레이어 페인트 통은 채우기 마스크나 타일 선택 중 더 적은 영역을 순회해
분산된 결과를 256px 청크로 생성한다. 선택의 부분 알파와 현재 프레임, 투명
무변경, Undo/Redo, 저장·재열기 및 저장 실패 롤백을 따른다. 참조 색상이 멀리
떨어져 있어도 현재 레이어가 변환되지 않은 청크이고 필터가 없으며 비연속 판정과
앤티앨리어싱 끄기인 경우, 청크를 개별 렌더링해 빈 중간 영역을 구체화하지 않는다.
이 참조 판정은 마술봉에도 적용하며 투명 바깥 영역도 색상 허용 오차에 따라
선택한다. 처리한 참조 픽셀은 최대 64MP이며 마스크·타일·이력 예산을 넘으면
문서와 Redo를 보존한다. 연속 판정, 참조 변환·필터, 앤티앨리어싱과 합성 참조의
큰 경계는 기존 제한을 따른다.

### 분산 선택의 현재 레이어 직접 채우기

유한 청크 레이어가 변환되지 않은 경우, 선택 또는 비연속 참조의 멀리 떨어진
영역을 빈 간격 없이 64px 패치로 계산해 한 번에 현재 레이어에 적용한다. 선택의
부분 알파와 알파 보존, 프레임별 자산 격리, 타일 이력과 Undo/Redo를 따른다.
고엔트로피 자산으로 전체 스냅샷을 이력에 보관할 수 없는 경우에도 변경 타일과
프레임 연결을 이력에 기록한다. 무변경·투명 결과는 Redo를 유지하며 작업·이력
예산 초과 또는 저장 실패는 기존 문서를 보존한다. 변환된 레이어의 넓은 분산
영역, 큰 연속 참조 및 합성 참조는 이전의 작업 한도를 따른다.

### 사각형·타원의 공통 도형 설정

사각형과 타원은 다각형과 같은 Tool 패널에서 칠·외곽선·선 두께·불투명도와
중심 기준 그리기를 설정한다. Shift는 정사각형 또는 원으로 비율을 제한하며
드래그 중 경계도 같은 설정을 따른다. 칠과 외곽선은 현재 전경색을 공유하고,
불투명도는 두 요소를 합성한 레이어에 한 번 적용한다. 0px 선은 만들지 않으며
칠도 없는 보이지 않는 설정과 크기 없는 도형은 문서와 Redo를 변경하지 않고
거부한다. 선택 마스크, 현재 프레임, Undo/Redo 및 저장·재열기를 따른다.
기존 프로그래밍 호출의 도형 스타일은 호환성을 위해 그대로 유지한다. 생성 후
벡터 앵커나 독립적인 칠·선 속성 편집과 다른 P1 도구들은 여전히 별도 작업이다.

### 복제 스탬프

Alt 클릭으로 원본 좌표를 지정하고 대상에 브러시 입력을 하면 획 시작 시
고정한 참조 이미지에서 픽셀을 복사한다. Current layer only는 현재 선택한
레이어를, 끄면 현재 프레임의 합성 결과를 참조한다. Aligned는 후속 획에도
원본과 대상의 오프셋을 유지하며, 끄면 각 획을 지정된 원본 좌표부터 시작한다.
원본 좌표는 문서 교체 시 폐기되며 프레임·대상·선택의 변경, 취소 또는
라이선스 해제 중인 획은 적용하지 않는다. 브러시 마스크와 원본의 알파 및 선택
마스크를 함께 적용하고 진행 중 결과를 미리 표시한다. 한 획은 단일 Undo/Redo이며
저장·재열기를 지원한다. 저장 실패와 무변경 획은 기존 이력을 보존한다.

현재 구현은 16MP 이하 유한 캔버스의 보이는 비변환 일반 래스터 대상에 한정되며
대상 필터와 청크 래스터는 지원하지 않는다. 원본 좌표 오프셋은 정수 픽셀이다.
미리보기 변경 영역이 64px 타일 1,024개를 넘으면 미리보기를 제공하지 않지만
획 적용은 별도로 시도한다. 전체 획 길이 기반 테이퍼와 정지 중 에어브러시 반복은
복제 스탬프에 아직 적용되지 않는다. 패턴 스탬프와 힐링 등 나머지 도구도 미구현이다.
이 기능은 헤드리스 통합 테스트로 검증했으며 실제 GUI·장치 실행 검증은 수행하지 않았다.
