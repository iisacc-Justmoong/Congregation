# 단일 앱 빌드 계약

제품은 [워크스페이스 단일 앱 정책](../../build-policy/README.md)를 사용합니다. `build/` 아래에 오직 정통 애플리케이션 번들이 생성됩니다. 테스트와 헬퍼는 일반 실행 파일이며, 런타임 배포 및 패키징은 원위치로 작동합니다. 정통 경로, 플랫폼 전환 및 검증 명령에 대한 정책을 참조하십시오.

2026-11-01의 읽기 전용 검사에서는 정통 `build/Congregation.app` 외에 이전 백업과
이행 작업 사본에 속한 앱 번들 19개가 발견되어 현재 빌드 트리는 이 정책을 아직
충족하지 않는다. 이 번들들은 이번 빌드 이전에 생성되었고 기존 작업을 보존하기 위해
삭제하지 않았다. 당시 목록은 빌드 산출물인 `build/lvui-menu-app-bundle-inventory.json`에
기록했으며 빌드 디렉터리를 정리하면 사라질 수 있다. 정리 전에는 각 사본의 보존
가치와 다른 작업의 사용 여부를 확인하고 워크스페이스 정책의 감사 절차를 따른다.
