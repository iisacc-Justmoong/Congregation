# 이전 Qt 배포 자동화 기록

이 디렉터리는 Qt 제품 빌드·Windows 서명·Qt 대응 소스 배포에 사용했던 워크플로를 보존한다. 현재 GitHub Actions의 실행 대상으로 사용하지 않는다. 이전 배포의 출처와 정책을 확인하기 위한 원본 설정이다.

현재 네이티브 빌드는 `.github/workflows/native-build.yml`과 `docs/BUILD.md`를 따른다. 운영체제에 맞는 사전 설치 iiSDK 키트와 그래픽 세션이 있는 자체 실행기가 필요하다. 이번 작업은 워크플로 소스 전환이며 원격 실행·서명·업로드를 수행한 결과가 아니다.
