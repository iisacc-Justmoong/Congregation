# 도구 속성의 앱 저장소 보존

사용자가 도구 패널의 저장 버튼을 누르면 현재 편집 가능한 도구 설정을 앱 데이터 디렉터리에 저장한다. 캔버스 파일이나 Society 컨테이너와는 별개이며, 앱을 다시 열 때 저장된 값을 복원한다. 저장하지 않은 이후 변경은 다음 실행에 반영되지 않는다.

저장 범위는 브러시별 수치와 필압 설정, 선택한 텍스처의 픽셀, 전경색과 배경색, 선택·채우기·복제·자르기·도형의 연결된 설정, 그라디언트 색상 정지점과 모드이다. Brush, Pencil, Airbrush, Mixer Brush, Dry Brush, Bristle Brush, Eraser, Smudge 및 Clone Stamp는 자기 브러시 설정을 유지한다. 도구 선택, 문서 내용과 취소 이력은 설정 저장에 포함하지 않는다. 아직 백엔드에 연결되지 않은 비활성 항목은 저장할 값이 없다.

`tool-preferences.bin`은 버전과 크기가 제한된 메타데이터 및 텍스처 데이터를 포함하며, 임시 파일에 모두 쓴 뒤 교체한다. 형식 오류나 잘린 입력은 부분 적용하지 않으며 읽기·쓰기 실패를 상태 영역에 알린다. 새 형식이 없으면 기존 `tools.ini`를 최대 128 KiB까지 읽는다. 기존 파일은 이행 중 삭제하지 않는다. 데이터 디렉터리는 macOS의 Application Support, iPadOS의 앱 샌드박스 및 Windows·Linux의 사용자별 앱 데이터 경로를 따른다.

자동 검사는 실제 앱 데이터 대신 격리된 테스트 디렉터리를 사용하고, 저장 후 새 뷰모델에서 복원, 미저장 변경, 각 도구의 독립성, 레거시 호환, 손상 및 쓰기 실패를 확인한다. 별도 테스트 프로세스로 저장과 복원을 나누어 메모리 공유 없이 파일을 읽는지도 검증한다. 이 검사는 앱의 실제 실행이나 기기별 설치를 뜻하지 않는다.
