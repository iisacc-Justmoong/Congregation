# 웹 로그인과 Society 실행 허가

Congregation은 계정 비밀번호와 라이선스 키를 입력받지 않는다. 기본 브라우저의
iisacc.com 로그인 페이지를 이용한다. 계정 객체는 iiLicenseManager의 구현과
라이선스 상태를 내부 소유하며, Society가 실제 앱 실행 허가를 판단한다.
Qt·QML·WebView를 사용하지 않는다.

## 흐름

1. iiAccountManager의 BrowserSession이 무작위 검증자와 S256 도전을 만들고 로그인 요청을 시작한다.
2. 서버가 발행한 정확한 iisacc.com 승인 페이지를 기본 브라우저에서 연다. 기존 로그인 화면에서 앱 연결을 승인한다.
3. 앱이 검증자를 사용해 일회성 요청을 교환한다. 불투명 세션은 Congregation과 현재 기기에 한정된다. 브라우저 쿠키·비밀번호·라이선스 키는 전달하지 않는다.
4. 앱은 같은 계정·기기에 대해 Society의 `127.0.0.1:49627/v1/authorize`에 실행 허가를 요청한다. 라이선스 서버에 직접 보유 여부를 요청하지 않는다.
5. Society 안의 iiAccountManager가 소유한 iiLicenseManager는 보안 저장소의 서명 토큰을 먼저 검증한다. 유효하면 서버 요청 없이 사용하고, 없거나 만료·변조되었을 때 서버에서 갱신한다.
6. 앱도 응답의 요청 ID와 서명 토큰의 계정·기기·제품·유효기간을 검증한다. 단순 `allowed: true`로 잠금을 풀지 않는다. 최대 30초마다 Society의 현재 허가를 확인한다. Society가 종료·중지된 동안에는 계정 SDK가 보관한 기존 서명 토큰을 만료까지 사용한다. 명시적인 허가 거부·미보유·로그아웃·만료·변조 시 편집을 잠그고 문서는 보존한다.

세션은 OS 보안 저장소의 `web-app-session-v1` 항목에 저장한다. 기존
`account-license` 항목이나 인증서 파일은 자동 삭제하지 않고 새 로그인에
사용하지 않는다. 시작 시 저장된 계정 식별자를 보안 저장소에서 복구한 뒤
Society의 허가를 확인한다. 계정 복구 자체는 실행 허가가 아니다.
Sign out은 앱 세션과 새 저장 항목을 해제한다. Cancel은 진행 중인 로그인만
중단하며 서버의 미완료 요청은 10분 후 만료된다.

Apple 기기 ID는 Society와 같은 해시 규칙을 사용한다. iPad는 IDFV,
Mac은 IOPlatformUUID가 기준이다. OS 식별자를 얻지 못한 경우
`account-device.id`의 설치 ID를 사용한다. Linux·Windows도 Society와 동일한 OS 식별자 해시 규칙을 사용하며, OS 식별자를 얻지 못한 경우에만 설치 ID를 사용한다.

`congregation://account-return`은 승인 후 앱으로 돌아오는 주소이며 인증정보를
담지 않는다. Open Society 버튼은 OS에 등록된 `society://account`를 연다.
처음 실행 허가를 받을 때 Society가 설치·실행되어 같은 계정에 연결되어 있어야 한다. 이후 승인된 토큰은 계정 SDK의 보안 스냅샷에 저장하며 복구할 때 서명을 다시 검증한다.
iPadOS도 같은 로컬 서비스 계약을 사용하며, Society 설치·생명주기의 실제
연결 검증은 Congregation 단독 설치·실행 증거와 구분해야 한다.

서버 서명 토큰은 기본 24시간 유효하며 세션과 제품 만료가 더 빠르면 그 시점이
상한이다. 오프라인 토큰의 원격 폐기는 다음 명시 갱신 또는 만료 때 반영된다.

업데이트는 앱 세션으로 인증하며 기존 크기·SHA-256·서명·호스트 검사를 유지한다.
Congregation 릴리스가 게시되지 않았다면 `update_release_unavailable`을 반환한다.

## 검증

`Congregation.services`는 실제 루프백 HTTP에서 웹 승인 후 Society 허가,
서버 요청 없는 로컬 재시작, Society 중지 시 기존 위임 유지, 반복 확인 시 뷰포트 보존, 미보유, 다른 계정·변조된 메모리 및 저장 토큰 거부, 로그아웃과
세션 기반 업데이트의 기존 검증 유지 여부를 검사한다. 일반 실행은 허가가
필요하며 기존 self-test만 테스트 전용 경로를 사용한다.
