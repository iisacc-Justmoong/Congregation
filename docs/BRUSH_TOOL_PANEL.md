# 브러시 도구 속성 패널

## 브러시별 상세 설정 계약

Figma의 Pencil `374:19167`, Airbrush `374:19618`, Mixer Brush `374:20079`,
Dry Brush `374:20554`, Bristle Brush `374:21024`는 일반 Brush와 같은 필압
곡선·동역학·텍스처·전송·효과·테이퍼 설정을 제공한다. 공통 설정은 하나의
LVUI 선언과 C++ 뷰모델에서 제공하고 각 도구의 고유 설정은 별도로 둔다.
동일한 설정을 같은 패널에 두 번 표시하지 않는다. 값을 조작하면 현재 획이
아닌 다음 획의 브러시 상태에 전달하며, 비활성 입력은 모델을 바꾸지 않는다.
필압 불투명도는 속도에 의존하지 않는다. 획은 기존 스트리밍 미리보기와
변경 픽셀 이력으로 확정하고 Undo/Redo의 결과는 동일해야 한다.

도구별 동작은 픽셀 정렬과 자동 지우기, 분사 범위·속도와 정지 중 분사,
혼합 소스와 붓 세척·충전, 마른 매체의 입자와 건조도, 붓모의 수·길이·두께·
강성·벌어짐을 포함한다. 수치의 단위와 선택 항목은 패널에 표시한다. 도구를
전환하거나 설정을 저장해도 서로 다른 도구의 편집값이 예상 밖으로 덮어쓰이지
않아야 한다.

각 브러시의 수치·토글·선택값, 절대 간격과 필압 곡선은 별도 프로필에 둔다.
버전 2 설정은 이 프로필을 함께 저장하고 버전 1은 기존 Brush 프로필로 읽는다.
선택한 텍스처 픽셀은 실행 중에는 도구별로 보존하지만 설정 파일에는 넣지
않으므로 재시작한 뒤에는 다시 선택해야 한다. Dry Brush는 기본 Paper 패턴을
제공한다. 일반 브러시는 Wetness 0으로 시작해 기존의 마른 경로를 사용하며,
기본 Wetness가 20인 Bristle Brush는 혼합이 활성화된 상태로 시작한다. 혼합
값을 바꾸면 Wetness가 0보다 클 때 혼합을 사용하고 0이면 마른 경로로 돌아간다.
기존 설정에서 사용하지 않던 Wetness 값은 마른 획을 유지하도록 0으로 전환한다.
초기화하면 해당 도구의 기본값으로 돌아간다. 간격 비율을 조정하면 이전의
절대 간격 지정은 해제되고 표시값은 실제 간격을 따른다.

Mixer의 모든 레이어 샘플은 획을 시작할 때 확정된 문서를 참조한다. 필요한
영역만 64×64 타일로 합성하고 캐시는 최대 256개 타일로 제한한다. 선택된
레이어만 샘플할 때는 기존 획 원본을 사용한다. 세척은 획이 정상 완료된 뒤
붓의 안료를 비우며, 충전은 현재 전경색으로 채운다. 둘 다 끄면 마지막으로
그린 위치에서 읽은 색을 다음 획의 안료로 사용한다. 취소한 획은 세척하거나
충전하지 않는다.

Figma `130:1836`의 브러시 패널은 기본 설정, Shape Dynamics, Scattering,
Texture, Color Dynamics, Transfer, Brush Pose, Noise, Wet Edges, Build-up,
Smoothing과 이후 상세 설정을 순서대로 제공한다. 기본 설정은 작은 슬라이더와
값을 사용하고 필압 불투명도·절대 간격·필압 곡선을 같은 위치에 둔다.
상세 설정의 값은 `ToolSettings`를 거쳐 iiPaintEngine의 브러시 상태에 반영한다.
동역학 제어는 목록에서 직접 선택하며, 해당 제어가 꺼져 있거나 현재 브러시가
지원하지 않는 설정은 비활성화하고 값 대신 대시를 표시한다. 예를 들어 Tilt
Scale은 크기 제어가 Pen Tilt일 때, Transfer의 Wetness와 Mix 동역학은 혼합
도구 또는 혼합이 활성화된 브러시에서 사용한다. 섹션 안의 간격보다 섹션 간
간격이 크다.

도구 속성의 화면 구성과 항목 순서는 `App/Tools/ToolPanel.lvui`에서
선언하고 빌드 시 네이티브 코드로 변환한다. 브러시 외의 선택·도형·채우기·
그라디언트·복제 도구 속성도 같은 화면에 포함한다. `ToolPanelBackend`는 기존
`EditorBackend`와 `ToolSettings`의 상태를 관찰해 각 행에 전달하고, 명령을
원래 모델에 보낸다. `ToolPanel.cpp`는 선언형 화면의 마운트와 필압 곡선의
네이티브 그리기 연결만 담당한다. 설정 변경은 캔버스 브러시와 팝오버에 같은
모델을 통해 반영되며 패널 세대가 끝나면 관찰도 해제된다.
반복되는 도구별 행은 선택기와 다른 입력의 조건 분기를 같은 수준에 둔다.
이를 통해 네이티브 선택기의 내부 버튼과 메뉴가 컨텐츠 중첩 한도 안에서
생성되며, 선택과 키보드 조작을 기존 LVUI 컴포넌트에 맡긴다.

기본 브러시 팝오버와 도구 패널은 크기, 유량, 불투명도, 경도, 간격과
스무딩 강도를 같은 모델에서 읽고 쓴다. 필압 불투명도를 끄면 기존 필압
바인딩도 비활성화하며, 이동 속도는 불투명도에 영향을 주지 않는다.
Noise의 Monochrome을 끄면 동일한 노이즈 입자 위치에서 색상 채널을 변화시키고
알파 마스크는 유지한다. 텍스처는 기존 자산 선택 동작으로 연결한다.

패널의 휠과 트랙패드 스크롤은 해당 뷰포트에 전달되고, 터치 장치에서는
손가락 또는 펜으로 한 번 세로 드래그해도 내용을 이동한다. 스크롤 가능한
뷰포트에서만 세로 제스처를 인식하며, 캔버스 펜 입력과 슬라이더의 가로
드래그는 기존 제어에 남는다. 두 손가락 스크롤과 확대 동작도 유지한다.

헤드리스 패널 시험은 항목 순서와 크기, 선택 메뉴, 값 연결, 사용 가능 상태,
휠과 터치 스크롤을 검사한다. 실제 iPad의 펜 입력과 표시 성능은 별도로
기기에서 확인해야 한다.

## 파라미터별 선택 갱신 명세

도구 설정을 바꾸면 실제로 값이 바뀐 파라미터와 그 값에 의존하는 사용 가능 상태만 갱신한다. 관계없는 행의 계산·알림과 패널 전체 재생성은 발생하지 않는다. 상대 간격을 조정할 때 절대 간격이 해제되는 경우, 최소·최대 불투명도가 함께 조정되는 경우, 혼합 상태가 변경되는 경우에는 실제로 바뀐 모든 파라미터를 각각 반영한다. 도구 전환·초기화·설정 복원에서도 이전 값과 달라진 항목만 갱신한다.

선택한 도구나 필압 설정처럼 행의 사용 가능 여부를 결정하는 입력은 영향을 받는 행에만 연결한다. 그라디언트의 종류·반복·혼합과 색상 정지점도 각각의 관련 행에만 알린다. 값이 그대로이거나 잘못된 입력, 취소된 복원은 알림을 보내지 않는다. 기존 브러시 엔진 연결과 도구별 프로필, 저장·복원, 스크롤과 포커스는 유지한다. 브러시 엔진에 설정을 적용할 때 다른 파라미터를 다시 쓰지 않는다.
