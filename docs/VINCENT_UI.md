# Vincent 화면 복원

이 문서는 이전 Vincent 배치의 이력이다. 현재 기본 화면은 [FIGMA_APPLICATION_WINDOW.md](FIGMA_APPLICATION_WINDOW.md)를 따른다.

기준은 Product/.Deprecated/Vincent의 3aeab4b 소스와 docs/marketing/vincent-windows-editor.png이다. Congregation의 docs/marketing/congregation-windows-editor.png도 같은 원본 화면을 보존한다. 제품명과 네이티브 런타임은 Congregation을 유지한다. Windows 제목·메뉴 막대는 플랫폼 영역으로 구분하고 앱 클라이언트 영역의 구성을 재현한다.

상단 40px 아이콘 도구 막대, 왼쪽 260px 레이어 목록, 20px 레이어 행과 중앙 캔버스를 사용한다. 파일/도구 아이콘과 160px 크기 슬라이더, 브러시 미리보기, 원형 현재색을 복원한다. 프레젠테이션과 프로필은 메뉴를 통해 연다. 브러시를 다시 누르면 설정 팝업이 열리고 도형은 메뉴에서 고른다. 색상 팝업은 280px 색상환·삼각형이다. 텍스트 도구의 입력은 별도 작은 팝업에서 편집한다.

환경설정은 480×360의 General, Profile, Members 탭이다. 시작 화면과 주변 사용자 탐색, 라이선스 복원·업데이트, 프로필 이미지/이름, 초대 허용과 공유 기능을 연결한다. 브러시 설정은 환경설정에서 도구 막대 팝업으로 옮긴다. 네이티브 메뉴에서 내보내기·이미지 배치·확대/축소·Undo/Redo를 실행할 수 있다.

CanvasView는 원본의 가로 9%, 세로 상단 12%·하단 10%, 최소 24px 여백으로 맞추며 작은 문서를 자동 확대하지 않는다. 편집기 이동과 UI 탭/팝업은 문서 리비전을 바꾸지 않는다. 프레젠테이션은 편집을 막고 도구 막대/레이어 목록을 숨기며 Escape로 복귀한다.

`--self-test build/native-tests --ui-reference docs/marketing/congregation-sample-artwork.png`는 격리된 설정·문서로 동일한 그림을 로드하고 편집기, 브러시, 색상, 도형, 환경설정 세 탭, 새 캔버스와 라이선스 화면을 캡처한다. 실제 사용자 저장 파일이나 자격 증명을 사용하지 않는다. CTest의 editor_layout, vincent_ui_native, vincent_ui_vulkan과 기존 standalone/relocation 검사를 실행한다. 최종 시각 비교 결과는 저장소 루트 design-qa.md에 기록한다.

## 추가 네이티브 계약

IconButton은 화면에 텍스트를 함께 표시하지 않고 accessibilityName으로 이름을 제공한다. 버튼은 16px 아이콘과 18px 너비를 사용한다. 파일·도구·브러시 구역의 간격은 보존된 화면에 맞춰 지정한다. 색상 버튼은 오른쪽 끝에 두고 환경설정·프레젠테이션은 네이티브 메뉴와 색상 버튼의 문맥 메뉴에서 연다. 레이어 하단 추가·삭제 버튼은 해당 영역에 포인터를 올렸을 때 표시한다. 기본 컨테이너 간격에 영향받지 않도록 편집기 구조의 gap을 0으로 고정한다. 도형 선택은 같은 버튼의 아이콘을 교체하며 포커스·명령 연결을 유지한다.

브러시 팝업은 픽셀 간격과 크기 비례 간격을 구분하고, 세 점 압력 곡선과 값 표시를 제공한다. 팝업이 닫혀 배치 크기가 0인 초기 상태도 안전하게 그린다. 새 캔버스 창은 숫자 범위(1..8192)와 무한 캔버스 여부에 따라 입력·Create 상태를 즉시 갱신한다. UI 상태만 바꾸는 동작은 문서 리비전을 변경하지 않는다.

## 원본 벡터와 창 크기

보존된 Windows 화면의 운영체제 테두리를 제외한 비교 영역은 1400×858이다. 같은 크기의 네이티브 클라이언트를 사용하며 캔버스 영역은 1140×818이다. 레이어 행 글자는 11px이다. SDK의 후속 아이콘 색상 변경이 원본 복원에 영향을 주지 않도록 resources/icons의 15개 SVG를 LVRS 29399482에서 가져왔고, panHand/translateObject 두 SVG는 보존된 Vincent 소스에서 가져왔다. 기존 LVRS/아이콘 라이선스 고지는 번들에 유지한다. 이 벡터들은 빌드 시 실행 파일에 포함되며 런타임 소스 경로에 의존하지 않는다.

창 크기를 변경하면 루트 위젯의 크기를 새 클라이언트에 맞춘다. 맞춤 상태의 캔버스는 다시 맞추고, 사용자가 확대·이동한 상태에서는 같은 문서 중심을 유지한다. 환경설정과 새 캔버스 창도 클라이언트 전체를 채운다.

레이어 가시성은 문맥 메뉴의 Show / hide layer에서 바꾼다. 화면을 상시 차지하던 상태 줄은 없애고, 실제 파일 작업 실패는 캔버스 위의 잠깐 표시되는 메시지로 전달한다. 메시지와 환경설정·팝업 전환은 문서 리비전을 바꾸지 않으며, 네이티브 실행 검사는 존재하지 않는 문서를 열었을 때 오류 표시와 기존 문서 보존을 함께 검증한다.

브러시 팝업의 슬라이더는 실제 배치 높이도 12px로 지정한다. 손잡이 그림만 줄이고 기존 32px 배치를 남겨 두면 그래프가 팝업 밖으로 밀리므로 둘을 함께 검증한다. 팝업은 내부를 클립하고, 그래프 드래그가 문서 그리기로 전달되지 않는지를 실제 포인터 검사에서 확인한다.

벡터의 기하를 유지하면서 보존 화면의 지우개 금색과 도형 회색을 적용했다. 이후 SDK의 아이콘 색상 개편이 이 화면에 재유입되지 않게 앱 소유 자산으로 고정한다.

iiGUI 입력 좌표는 창 표면 기준이다. 애플리케이션 어댑터가 캔버스·압력 그래프의 실제 배치 원점을 빼서 로컬 좌표로 변환한다. 이를 문서 좌표로 다시 변환하여 펜과 이미지·텍스트 배치에 사용한다. 실행 검사는 첫 스트로크 원점의 실제 문서 픽셀과 그래프 조절점 값을 확인한다.

Undo/Redo는 상단 도구 막대 대신 원본처럼 네이티브 Edit 메뉴와 단축키로 접근한다. 실행 검사도 삭제된 임시 버튼에 의존하지 않고 창 입력 경로의 Cmd/Ctrl+Z 및 Shift 조합을 검증한다.

도형·레이어·색상·프로필의 평면 문맥 메뉴는 빈 단축키 자리와 하위 메뉴 화살표를 표시하지 않는다. 실제 명령에 없는 key 자리표시자를 숨겨 긴 이름도 한 행에서 읽히도록 한다.
