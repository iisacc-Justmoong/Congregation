# 도구별 속성 패널

기준은 Congregation Figma 파일 `r4E0PNUdZuo6dEiMEitF2I`의
`01 · Selection, Crop & Sampling`부터 `05 · View, Mask & Symmetry`까지의
도구별 예제와 `Brush · Complete Settings`다. 브러시를 포함한 47개 도구에
각자의 제목, 섹션, 항목 순서와 컨트롤을 제공한다. 비슷한 도구도 별도 패널이다.

도구 막대에서 도구를 선택하면 해당 패널을 표시한다. 아직 캔버스에서 지원하지
않는 도구도 패널을 미리 볼 수 있지만 현재 캔버스 도구는 변경하지 않는다. 이러한
경우 상태 표시줄이 도구를 사용할 수 없음을 알린다. 엔진에 연결되지 않은 컨트롤은
Figma의 기본값을 표시하며 비활성화한다. 이미 지원하는 브러시, 선택, 자르기,
채우기, 도형 및 그라디언트 설정은 기존 편집기 모델의 값을 표시하고 변경한다.

색상 선택기는 Figma의 해당 도구 예제에 포함된 경우에만 표시한다. 도구 설정은
LVUI의 공통 컴포넌트와 스타일 토큰을 사용하며, 고정 높이로 잘리지 않도록
스크롤한다. 도구별 항목 목록은 애플리케이션에 정적으로 컴파일되고, 표시 상태와
기존 편집기 설정은 C++ 뷰모델이 제공한다.

Figma `84:9425`에서 우측 상단은 세그먼트만 있는 30px 높이의 영역이다.
도구·생성·문서·자산 세그먼트는 `84:9464`에 맞춰 22px 아이콘 버튼 네 개와
2px 간격을 유지하며 묶음의 자연 폭인 94px을 사용한다. 색상 선택기는 그 바로
아래에 오며 별도의 Options 제목이나 현재 도구 행은 두지 않는다.

기본 Brush 패널은 `84:9425`처럼 Brush 설정 섹션으로 바로 시작하며 중복 도구
제목, 프리셋 선택기와 조작 안내 행을 표시하지 않는다. 다른 도구는 `420:45393`의
Move 예제처럼 해당 속성 패널 안에 제목을 표시한다. 제목 행은 파라미터 열의
왼쪽에 정렬하며 아이콘 영역은 22px, 아이콘과 13px 본문 제목 사이는 8px이다.
기존 프리셋 모델은 유지하지만 이 패널에서는 프리셋 선택기를 제공하지 않는다.

`Congregation.tool_panel_catalog`는 도구 및 패널 목록을 검증하고,
`Congregation.independent_tool_panel`은 패널 교체, 항목 노출, 기존 설정 연결과
스크롤과 제목 표시·정렬을 검사한다. `Congregation.independent_workspace`는 도구별
색상 선택기 노출, 상단 배치와 세그먼트 크기·간격·전환을 검사한다. 이들은 창을
띄우지 않는 테스트이며 실제 기기 실행을 뜻하지 않는다.
